# Claude Frontend Guidance

For every frontend task, read rules in this order:

1. Repository-wide [AGENTS.md](../AGENTS.md) for shared project guardrails and conventions.
2. Frontend [AGENTS.md](AGENTS.md) for the frontend entry point and required workflow.
3. Canonical frontend [docs/FRONTEND_RULES.md](docs/FRONTEND_RULES.md) for Next.js architecture, dependencies and implementation rules.

Apply common rules and frontend rules together. Where they overlap, use the stricter requirement.
